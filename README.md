# 🚀 Dimuthu's Personal Portfolio

Welcome to my personal portfolio repository! This project showcases my skills, experience, and the creative work I've done as a Graphic Designer, Art Director, and budding Software Developer.

## 🌐 Live Site
Check out the live version of my portfolio here: **[https://dimuthulk.vercel.app/](https://dimuthulk.vercel.app/)**

## 👨‍💻 About Me
I'm **Dimuthu Rathnayaka**, a passionate Art Director and Graphic Designer with over 9 years of industry experience. I specialize in turning ideas into visually powerful designs across print and digital platforms. 

Currently, I'm expanding my horizons as an Electronics and Computer Science undergraduate at the University of Kelaniya, diving deep into software development, Next.js, React, and exploring the broader tech ecosystem including DevOps, AI, and Cybersecurity.

## ✨ Features
*   **Modern Design:** Sleek and responsive UI tailored to showcase creative projects.
*   **Projects Section:** Detailed case studies of my design and development work.
*   **Experience Timeline:** A visual journey of my professional career.
*   **Tech Stack:** Highlights my proficiency in both design tools (Adobe Creative Suite) and development technologies (Next.js, React, Git).

## 🛠️ Built With
This portfolio is built using modern web technologies to ensure performance and scalability:
*   **Framework:** Next.js / React
*   **Styling:** SCSS / Tailwind CSS
*   **Deployment:** Vercel
